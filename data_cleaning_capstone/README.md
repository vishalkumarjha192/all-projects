# Data Cleaning Capstone Project

## Project title
**Student Records Data Cleaning and Quality Validation**

## Objective
Clean a raw student dataset so it is consistent and ready for reliable analysis.

## Tools
- Python 3
- pandas
- CSV files

## Files
- `students_raw.csv` — intentionally messy sample data (synthetic)
- `clean_data.py` — reproducible data-cleaning script
- `students_cleaned.csv` — cleaned output, generated by the script
- `cleaning_report.txt` — summary of rows and cleaning actions, generated by the script

## How to run
1. Install Python 3.
2. Install pandas: `pip install pandas`
3. Place all project files in the same folder.
4. Run: `python clean_data.py`

## Data-cleaning workflow
1. Inspect the raw records and missing values.
2. Remove exact duplicate rows.
3. Trim extra spaces and standardize text/categorical values.
4. Convert age, score, and attendance into numeric fields.
5. Apply validation rules (age 16–100, score 0–100, attendance 0–100%).
6. Fill missing numeric values with column medians.
7. Validate email format and flag duplicate student IDs.
8. Export the cleaned dataset and cleaning report.

## Expected outcome
A consistent CSV file with normalized categories, numeric columns, basic validation flags,
and a report documenting the cleaning operations.

## Important
The included records are fictional and intended only for practice. Median imputation is a
demonstration choice; for a real project, explain and validate the strategy with the project
requirements or supervisor.
